# Pollution Analysis System

This is a Python-based pollution analysis project developed using Pandas and Matplotlib.

## Features

* Air Pollution Analysis
* Water Pollution Analysis
* Noise Pollution Analysis
* Soil Pollution Analysis
* Pie Charts
* Bar Graphs
* Scatter Plots
* Correlation Heatmap

## Technologies Used

* Python
* Pandas
* Matplotlib
